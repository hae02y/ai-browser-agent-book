# 도식·이미지 검토 기록

검토일: 2026-11-27. 이 기록은 저장소의 도식 파일과 원고의 대응을 확인한 결과다. 제품 화면의 실제 사용이나 위키독스 공개 렌더링을 확인한 결과는 아니다.

## 현재 이미지 구성

- 00~21장에 `assets/diagrams/chapter-NN-flow.svg`가 각각 하나씩 있다. 처음 20장 도식은 저장소의 `docs/STATUS.md`에서 2026-11-02 저자 제작이라고 기록되어 있다. 새 19장(데스크톱)과 20장(모바일) 도식은 2026-11-27에 이 개정에서 만들었다. 기존 전망 장의 도식은 21장으로 이동했다.
- 22개 SVG는 XML 파싱에 성공했고, 각 장의 이미지 경로·대체 텍스트·SVG `<title>`이 일치한다. 모든 SVG에 `role="img"`와 `<title>`·`<desc>`가 있다. 외부 이미지, 스크립트, `foreignObject`, 외부 `href` 참조는 발견되지 않았다.
- 본문에는 실제 제품 화면 캡처가 없다. 자체 도식은 제품 기능의 증거가 아니므로 캡션에서 실제 제품 화면이 아니라고 밝히고 있다.
- 2026-11-27에 20장의 공통 캡션을 각각 그림이 보여 주는 관계를 설명하는 고유한 문장으로 바꿨다. 저자 제작 도식이며 실제 제품 화면이 아니라는 표시는 유지했다.

## 게시 전 남은 검증

1. 위키독스 GitHub 연동 책을 만든 뒤 공개 페이지에서 SVG가 실제 표시되는지 확인한다. 로컬 파일 존재와 XML 파싱은 공개 렌더링 검증을 대신하지 않는다.
2. 제품 화면을 추가한다면 공식 출처·이용 조건·촬영 날짜·계정 정보와 개인 정보 노출 여부를 별도로 기록한다. 현 도식에는 외부 제품 화면을 포함하지 않는다.
