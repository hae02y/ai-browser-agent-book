검토일: 2026-11-27. 이 기록은 저장소의 도식 파일과 원고의 대응을 확인한 결과다. 제품 화면의 실제 사용이나 위키독스 공개 렌더링을 확인한 결과는 아니다.

## 표지와 전용 로고

- `assets/computer-use-ai-cover.png`: 2026-11-27에 이 책을 위해 이미지 생성 도구로 만든 원본 일러스트를 편집하여 정확한 한국어 제목과 창 모양 마스코트 로고를 넣었다. 1024×1536픽셀, RGB, 약 1.8MB. 제목은 「처음 만나는 컴퓨터 사용 AI」, 부제는 「화면을 보고 대신 일하는 에이전트」로 시각 대조했다. `README.md`와 00장 첫머리에 삽입했다.
- `assets/computer-use-ai-logo.png`: 같은 표지의 마스코트를 참고해 별도로 생성한 투명 배경 로고. 1536×1024픽셀, RGBA, 약 1.0MB. 창·눈·커서를 결합한 이 책의 식별 그림으로 사용한다.
- 두 이미지는 외부 제품 로고나 실제 서비스 화면을 복사하지 않은 생성 일러스트다. 원본 프롬프트는 컴퓨터 화면을 관찰하고 행동 결과를 확인하는 책의 주제와, 회사 상표·문자·워터마크 배제를 요구했다. 인쇄나 외부 판촉에 쓰기 전에는 최종 사용 조건과 실제 출력 품질을 다시 확인한다.
- 위키독스 00장의 첫 이미지로 게시했다. 별도 책 표지 설정은 계정 도구에서 제공되지 않아 지정·확인하지 못했다.

## 현재 이미지 구성

- 00~21장에 `assets/diagrams/chapter-NN-flow.svg`가 각각 하나씩 있다. 처음 20장 도식은 저장소의 `docs/STATUS.md`에서 2026-11-02 저자 제작이라고 기록되어 있다. 새 19장(데스크톱)과 20장(모바일) 도식은 2026-11-27에 이 개정에서 만들었다. 기존 전망 장의 도식은 21장으로 이동했다.
- 22개 SVG는 XML 파싱에 성공했고, 각 장의 이미지 경로·대체 텍스트·SVG `<title>`이 일치한다. 모든 SVG에 `role="img"`와 `<title>`·`<desc>`가 있다. 외부 이미지, 스크립트, `foreignObject`, 외부 `href` 참조는 발견되지 않았다.
- 본문에는 실제 제품 화면 캡처가 없다. 자체 도식은 제품 기능의 증거가 아니므로 캡션에서 실제 제품 화면이 아니라고 밝히고 있다.
- 2026-11-27에 20장의 공통 캡션을 각각 그림이 보여 주는 관계를 설명하는 고유한 문장으로 바꿨다. 저자 제작 도식이며 실제 제품 화면이 아니라는 표시는 유지했다.

## 게시 후 남은 검증

1. 위키독스에 각 SVG를 PNG로 변환해 게시했다. 표지와 00장 도식의 이미지 주소는 HTTP 200 응답을 확인했다. 책·본문 주소는 외부 HTTP 요청에 403을 반환하므로 실제 브라우저 표시와 책 목록 썸네일은 확인이 남았다.
2. 제품 화면을 추가한다면 공식 출처·이용 조건·촬영 날짜·계정 정보와 개인 정보 노출 여부를 별도로 기록한다. 현 도식에는 외부 제품 화면을 포함하지 않는다.
