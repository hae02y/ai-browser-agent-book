2026-11-27 게시: [위키독스 책 22357](https://wikidocs.net/book/22357)에 00~21장 22개 페이지를 일반 책으로 공개했다. 위키독스 계정 도구의 목차 조회에서 22개 페이지 모두 `open_yn=Y`, 순서 0~21을 확인했다. 00장 본문에 전용 표지와 도식을 넣고, 각 장 SVG 도식을 PNG로 변환해 위키독스 이미지 저장소에 올렸다. 표지·00장 도식 주소는 HTTP 200과 이미지 형식 응답을 확인했다. 외부 HTTP로 책·본문 주소를 열면 403이 반환되어 실제 브라우저 렌더링은 확인하지 못했다. 책 목록의 별도 표지 설정도 확인·지정하지 못했다. GitHub PR #1은 squash 병합했으며 위키독스 일반 책과 GitHub 저장소는 자동 연동되지 않는다.

2026-11-27 개정: 기존 책이 선택한 '컴퓨터 사용 AI' 주제와 겹침을 확인했다. 새 저장소를 만들지 않고 제목을 「처음 만나는 컴퓨터 사용 AI: 화면을 보고 대신 일하는 에이전트」로 정해 개정했다. `docs/AGENT_HARNESS.md`와 `docs/WORK_QUEUE.md`에 조사→장별 집필→표지·그림→독립 QA→게시 검증의 역할과 인계 기준을 만들었다. 00~18장을 개정하고 19장 데스크톱·20장 모바일을 추가했으며 전망을 21장으로 옮겼다. 공식 제품 자료는 `docs/SOURCE_LEDGER.md`에, 그림 확인은 `docs/IMAGE_LEDGER.md`에 기록했다. `python3 scripts/check_book.py`로 22장 목차와 상대 링크·그림 경로를 확인했다. 독립 QA에서 지적한 범위 불일치를 새 장으로 보완하고 공식 근거·실습 표현·구조 재검수를 통과했다. 실제 서비스 실습은 아직 하지 않았다.
