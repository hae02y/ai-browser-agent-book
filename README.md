# 처음 만나는 AI 브라우저: 클릭하고 실행하는 컴퓨터 사용 에이전트

AI에게 질문하는 시대에서, AI가 실제 브라우저를 열고 검색하고 버튼을 누르고 결과를 확인하는 시대로 넘어가고 있습니다. 이 책은 개발자가 아니어도 AI 브라우저 에이전트가 무엇인지, 어떤 원리로 작동하는지, 어디까지 맡겨도 되는지 이해하도록 돕습니다.

## 이 책에서 다루는 것

- 챗봇과 브라우저 에이전트의 차이
- 화면·DOM·접근성 트리·스크린샷을 읽는 방식
- 관찰 → 계획 → 클릭 → 검증의 실행 루프
- Browser Use, Browser Harness, Playwright의 역할
- 검색·자료조사·반복 입력을 안전하게 자동화하는 방법
- 로그인·권한·파일·결제·개인정보의 경계
- 프롬프트 인젝션과 악성 웹페이지
- 실패·재시도·중단·복구·감사 로그
- 비개발자용 첫 실습과 업무별 체크리스트

## 자료 확인 기준

2026년 10월 26일. 인기 수치는 이 날짜에 확인한 공개 지표이며, 시간이 지나면 달라질 수 있습니다. Browser Use와 Browser Harness의 GitHub 수치, 2026년 에이전트 브라우저 트래픽 보고서, Stack Overflow 2026 AI 설문을 참고했습니다.

## 상태

새 책의 구조와 집필 지침을 만들고 집필을 시작했습니다. 실제 위키독스 책 생성과 공개 발행은 원고·이미지·출처 검수가 끝난 뒤 진행합니다.
